A [make.fun](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) entry for the **One-Line Robot Wedding Vows** bounty: a program that writes a single funny line of wedding vows for a robot couple — at most 160 characters — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

It writes the entry line to `/output/entry.txt` (131 characters, one line).

## The line

> I promise to love you in sickness and in low battery, through every firmware update, until death — or a factory reset — do us part.
